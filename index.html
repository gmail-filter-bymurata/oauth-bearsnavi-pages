サービス概要

最終更新: 2026年9月14日

本ツールは一般の求職者向けサービスではありません。 ベアーズナビ株式会社の社内業務ツールであり、当社が許可した社内アカウントのみが利用できます。 一般の方が登録・利用することはできません。

何をするツールか

当社のキャリアアドバイザー（以下「CA」）が求職者と行った面談について、 記録の整理・振り返り・CAの教育を目的に使う社内ツールです。

  • 面談ごとの記録（日時・担当CA・関連ファイルへのリンク）を一覧できるようにする
  • 会議メモを構造化し、面談で何が話され、どのような支援が行われたかを振り返れるようにする
  • 他のCAが学べる面談を、管理者が「教育ライブラリ」として認定・共有する

求職者への提案内容の自動生成や、求職者の評価・スコアリングを目的としたツールではありません。 評価の対象は当社CAの面談技術です。

Google アカウントとの連携

当社CAがGoogle Meetで実施した面談の録画と、Googleが自動生成した会議メモは、 各CAのGoogleドライブに保存されます。本ツールはこれを参照するために、 CA本人の同意のもと、読み取り専用の権限でGoogleアカウントと連携します。

使うAPI目的権限
Google Drive API Google Meet が作成した録画・会議メモのファイル情報（ファイル名・作成日時・閲覧リンク）を取得する 読み取りのみ
Google Docs API 会議メモ（Googleドキュメント）の本文を取得する 読み取りのみ
  • ファイルの作成・変更・削除・移動は一切行いません。 その処理をコードとして実装しておらず、Google APIへ送信できるHTTPメソッドも プログラム上で読み取り系に限定しています。
  • 録画（動画・音声）の実体はダウンロードも保存もしません。 Googleドライブ上の原本へのリンクのみを保持します。
  • Googleのパスワードを入力・保存することはありません（OAuth 2.0 を使用します）。

取り扱う情報

会議メモには求職者の氏名などが含まれることがあります。本ツールでは、 氏名・メールアドレス・電話番号・住所・URLを匿名化した状態で保存し、 マスキング前の原文は保存しません。

取得する情報の詳細、利用目的、保存しない情報、削除の方法は プライバシーポリシーに記載しています。
