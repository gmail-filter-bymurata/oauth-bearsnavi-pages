プライバシーポリシー

最終更新: 2026年9月14日

本ポリシーは、ベアーズナビ株式会社（以下「当社」）が提供する社内業務ツール 「CA面談インテリジェンス」（以下「本ツール」）における情報の取り扱いを定めるものです。 本ツールの概要はサービス概要をご覧ください。

1. 取得するGoogleユーザーデータ

1-1. ログインのために取得する情報

本ツールへのログインにGoogleアカウントを使用します。取得するのは次の情報です。

  • メールアドレス
  • 表示名・プロフィール画像（スコープ openid email profile）

1-2. 面談データの取得のために連携する権限

当社CAが本人の意思でGoogleアカウントを接続した場合に限り、次の読み取り専用スコープを要求します。

スコープ取得する内容
https://www.googleapis.com/auth/drive.meet.readonly Google Meet が作成したファイル（録画・会議メモ）のファイル名、MIMEタイプ、サイズ、作成日時、更新日時、閲覧リンク、所有者のメールアドレス
https://www.googleapis.com/auth/documents.readonly 会議メモ（Googleドキュメント）の本文テキスト
openid email 接続したGoogleアカウントの識別子とメールアドレス

いずれも読み取り専用です。Googleドライブ上のファイルを作成・変更・削除・移動する機能は 本ツールに実装されていません。

2. 利用目的

  • 面談記録の整理と、担当CA本人および管理者による振り返り
  • 会議メモの構造化（面談で何が話され、どのような支援が行われたかの記録）
  • 他のCAの教育教材として活用できる面談の選定・共有

広告目的では使用しません。第三者へ販売・貸与しません。 求職者個人の信用評価や、当社以外への提供のために使用することもありません。

3. 保存する情報 / 保存しない情報

3-1. 保存する情報

区分内容
面談タイトル、開始日時、所要時間、担当CA、処理状態
ファイル情報GoogleドライブのファイルID、ファイル名、MIMEタイプ、サイズ、閲覧リンク、作成／更新日時、所有者メールアドレス
会議メモ匿名化処理を施したテキストのみ。あわせて文字数、匿名化した項目の件数、原文のハッシュ値（更新検知用）
求職者社内管理用の氏名、匿名ID、メールアドレス・電話番号のハッシュ値のみ
接続情報接続したGoogleアカウントのメールアドレスと識別子、付与されたスコープ、暗号化した更新トークン（AES-256-GCM）
解析結果面談の要約・評価、タグ、担当者のコメント、操作の監査ログ

3-2. 保存しない情報

  • 録画（動画）・音声の実体 — ダウンロードせず、Googleドライブ上の原本へのリンクのみを保持します
  • 会議メモの原文 — 匿名化前のテキストはデータベースに保存しません
  • 求職者のメールアドレス・電話番号の生の値 — ハッシュ値のみを保存します
  • Googleのパスワード — 入力も保存も行いません
  • アクセストークン — 必要の都度取得し、データベースには保存しません

3-3. 匿名化について

会議メモは、氏名・メールアドレス・電話番号・住所・URLを [候補者] [CA] [EMAIL_1] のようなトークンへ置換したうえで保存します。 ただし日本語の自由文から個人を特定しうる記述をすべて機械的に除去することはできません。 勤務先名・経歴など、氏名以外の記述が残る場合があります。本ツールはこれを前提に、 後述のアクセス制御と併せて保護しています。

4-1. AIによる解析について

面談の構造化にはAIを利用します。取り扱いは次のとおりです。

  • 本ツールから外部のAI APIへ自動送信することはありません。 アプリケーションにAI APIを呼び出す機能は実装されていません。
  • 解析は、当社の管理者が手動の操作として、 匿名化済みのテキストのみをAI開発ツール（Anthropic社のClaude）で処理する運用としています。 匿名化前の原文、録画、ファイルそのものを渡すことはありません。
  • 過去に実施した解析においても、送信したのは匿名化済みのテキストのみです。

これら以外に、取得した情報を第三者へ提供・販売することはありません。

5. Google API Services User Data Policy への準拠

本ツールによるGoogleユーザーデータの取得・利用・保存・共有は、 Google API Services User Data Policy （Limited Use requirements を含む）に準拠します。具体的には次を遵守します。

  • 取得したデータは、本ツールの機能を提供・改善する目的にのみ使用します
  • 広告を目的としてデータを使用しません
  • データを第三者へ販売しません
  • データを人が読むのは、次の場合に限られます
    • データを提供したGoogleアカウント利用者（当社CA）の同意がある場合
    • セキュリティ上の目的（不正調査・障害対応）
    • 法令の遵守に必要な場合
    • 集計され匿名化されたデータであって、社内運用のために用いる場合

本ツールは、当社CAが自身の面談を振り返り、管理者が教育教材を選定するために、 匿名化済みの会議メモを社内担当者が閲覧することを前提としています。 これはアカウントを接続したCA本人の同意にもとづくものであり、接続時に説明しています。

6. アクセス制御と安全管理

  • 招待制です。管理者が事前に登録したアカウントのみ利用できます。 Googleアカウントを持っているだけでは利用できません。
  • 担当CAは自分の面談のみ閲覧できます。全件を閲覧できるのは管理者のみです。 他のCAが閲覧できるのは、管理者が教育教材として認定した面談に限られます。
  • データベースは行レベルセキュリティを既定で拒否に設定し、 加えて一般公開用のキーからはテーブルへの権限そのものを剥奪しています。 画面から直接データベースへ接続することはできません。
  • Googleの更新トークンはAES-256-GCMで暗号化して保存し、 画面・APIの応答・ログのいずれにも出力しません。
  • ログには個人情報・会議メモの本文・トークンを出力しません。

7. 保存期間

面談記録および解析結果は、社内での振り返り・教育目的のために保存します。 求職者ご本人または当社CAからの削除のお申し出があった場合、 および社内で保存の必要がなくなったと判断した場合には削除します。

8. 連携の解除とデータの削除

8-1. Googleアカウントの連携解除

  • 本ツールの「接続設定」画面から解除できます。解除するとGoogle側のトークンを失効させ、 当社に保存された暗号化トークンも消去します。
  • Googleアカウント側からも アカウントにアクセスできるアプリ からいつでも取り消せます。
